# imt542-i4

## What does the app do?
The app pulls data from 3 types of information structure - HTML, JSON and image data (jpg). It fetches game data from Steam and export into a JSON file, it reads data from an image and gives it to ChatGPT to get a text description, and it crawls through an HTML and prints out the raw code.

## How to run
Set the ```CURR_DIR``` to the current directory path you have. You need an OpenAI API key also, which can be grabbed for free from OpenAI. Run the Python file ```data_process.py```. In case of issues when running the app, I will provide an example output below.
